## 🎨 Détails Design

### Gradients Utilisés
```css
/* Primary Gradient */
linear-gradient(135deg, #0087a9 0%, #00a8cc 100%)

/* Background Gradient */
linear-gradient(135deg, #f5f7fa 0%, #c3cfe2 100%)

/* Card Background */
linear-gradient(135deg, #ffffff 0%, #f8f9fa 100%)
```

### Ombres
- **Petite** : `0 2px 4px rgba(0, 0, 0, 0.08)`
- **Moyenne** : `0 4px 12px rgba(0, 0, 0, 0.1)`
- **Grande** : `0 8px 24px rgba(0, 0, 0, 0.12)`
- **Hover** : `0 12px 40px rgba(0, 135, 169, 0.2)`

### Bordures
- **Rayon standard** : 10px - 16px
- **Rayon boutons** : 50px (pill shape)
- **Rayon modals** : 20px
